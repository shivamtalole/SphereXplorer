========================================================================
SphereXplorer — NASA SPHEREx Interactive Web Experience
========================================================================

Congratulations! This package contains the complete, production-ready
public website for SphereXplorer.

HOW TO MAKE THIS PUBLIC IN 1 MINUTE (FREE HOSTING):

Option 1: Netlify Drop (Easiest — Zero Setup)
1. Open https://app.netlify.com/drop in your web browser.
2. Drag and drop this extracted folder onto the page.
3. Your website will be instantly live with a free HTTPS URL!

Option 2: Vercel (Fast & Professional)
1. Go to https://vercel.com/new
2. Drag and drop this folder or connect your Git repository.
3. Instant global edge deployment.

Option 3: Any Traditional Web Host (Apache, Nginx, cPanel)
1. Upload all files (index.html, assets folder, etc.) to your public_html or root web directory.

Files in this bundle:
- index.html: Main application shell
- assets/: Bundled React, Three.js 3D galaxy engine, CSS & NASA observatory render
- spherex-icon.svg: Custom orbital mission brand icon
- galaxy-standalone.html: Standalone single-file 3D particle galaxy demo
